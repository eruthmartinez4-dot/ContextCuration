# Portfolio Plan

Last reviewed: 2026-10-14
Goal: three small, well-documented public GitHub projects that support a move into ML engineering by March 2028.

## Project 1: Member Churn Early-Warning (capstone)

- Shows: tabular ML, imbalanced classes, calibration, SHAP explanations, synthetic data generation.
- Gap to close before publishing: a short model card, a reproducible pipeline (make or a single run script), and a small dashboard.
- Target publish date: shortly after the 2026-12-11 final presentation.

## Project 2: Personal Context Assistant (this studio)

- Shows: local LLMs with Ollama, retrieval with ChromaDB, comparison against a frontier model (Gemini Flash), and later a knowledge graph and an MCP server.
- Built on the class ContextCuration repository with my own curated context folder.
- What would make it stand out: a fixed evaluation question set, clear comparison results, and an honest write-up of failure cases.

## Project 3: Balcony Garden Sensor

- Shows: embedded hardware, MQTT, Home Assistant integration.
- Status: firmware now in MicroPython (see October reflections). Needs a README with wiring photos and calibration notes.
- Lowest priority of the three; publish only if time allows.

## Portfolio rules I set for myself

- Every project gets a README with: problem, approach, how to run, results, limitations.
- No secrets or real personal or member data in any repository.
- Prefer finishing one project properly over starting a fourth.
